# Abstractive Summarization of Legal Documents Using Fine-Tuned Small Language Models

## Project Overview
This project explores the use of Generative AI and Natural Language Processing (NLP) to summarize lengthy legal documents into concise, readable summaries while preserving their important meaning.

## Problem Statement
Legal documents often contain lengthy, complex language that is difficult for ordinary users to understand. Reading and analyzing these documents requires significant time and effort.

## Objectives
- Simplify lengthy legal documents.
- Generate concise summaries using AI.
- Preserve important legal information and context.
- Explore small language models for summarization.
- Build a user-friendly application for document analysis.

## Technologies
- Python
- Natural Language Processing (NLP)
- Generative Artificial Intelligence
- Small Language Models
- Streamlit (for the user interface, if used)

## Project Workflow
1. Upload a legal document.
2. Extract text from the document.
3. Preprocess the extracted text.
4. Generate an abstractive summary using a language model.
5. Display the summarized content.

## Project Status
Academic project under development.

## Disclaimer
The generated summaries are intended for educational and informational purposes only. They are not a substitute for professional legal advice.
